# Bot Improvements

This version changes the bot only. Existing server connection settings are preserved.

## Improvements
- Varied waypoint-based movement
- Pathfinder-based navigation
- Random looking and occasional jumping
- Stuck detection and movement-goal recovery
- Safer reconnect/error handling
- Reduced unnecessary chat spam
- Cleaner movement state handling
- Added documentation

The bot does not modify the Minecraft server or hosting configuration.
